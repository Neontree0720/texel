# Texel (웹 버전)

마인크래프트 리소스팩을 브라우저에서 바로 만드는 편집기입니다. 데스크톱 앱 Texel과 같은 화면·기능을 씁니다.

- 텍스처 그리기 (레이어, 팔레트, 텍스처 고정, 원본 나란히 보기)
- 텍스트/번역, 소리 교체, 팩 정보·아이콘 편집
- **.zip 내보내기**로 받은 파일을 `.minecraft/resourcepacks` 폴더에 넣으면 적용됩니다.

## 저장 위치

- 기본: 브라우저 저장소(OPFS). 브라우저의 사이트 데이터를 지우면 함께 지워지니 가끔 .zip으로 백업하세요.
- Chrome·Edge: "폴더 열기" 또는 저장 위치 "변경"으로 내 컴퓨터 폴더를 직접 쓸 수 있습니다.

## 구조

정적 사이트입니다. 빌드 과정 없이 Vercel에 그대로 배포됩니다.

| 파일 | 하는 일 |
| --- | --- |
| `index.html`, `styles.css`, `js/` | 앱 화면 (데스크톱 앱의 renderer 와 같은 코드) |
| `js/web-api.js` | 데스크톱 앱의 Electron 메인 프로세스 대신, 브라우저 안에서 파일 저장·다운로드를 처리 |
| `sw.js` | 서비스 워커. `/mc/...` 그림·소리 주소를 web-api.js 로 연결 |
| `vercel.json` | `/mcres/*` → `resources.download.minecraft.net` (그쪽 서버가 CORS 를 허용하지 않아서 대신 받아 줌) |

이 저장소의 파일은 데스크톱 앱 프로젝트에서 `node scripts/build-web.js <이 폴더>` 로 만들어집니다.

마인크래프트 원본 파일은 Mojang 공식 서버에서 사용자의 브라우저로 직접 받으며, 이 사이트에 올려 두지 않습니다.
Texel은 Mojang/Microsoft와 관련 없는 비공식 도구입니다.
